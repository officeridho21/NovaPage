# NovaPage — Company Profile

React + Vite + Tailwind CSS + AOS.

## Menjalankan
```bash
npm install
npm run dev      # development
npm run build    # production build -> folder dist
```

## Mengubah isi
- Semua teks, nomor WhatsApp, email: `src/data/content.js`
- Logo: `src/assets/logo.png` (wordmark) dan `src/assets/logo-mark.png` (ikon)
- Gambar hero: `src/assets/hero.svg` — ganti dengan foto sendiri
  (import di `src/components/Hero.jsx`, mis. `hero.jpg`)
- Warna & font: `tailwind.config.js`
